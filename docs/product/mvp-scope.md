# Обсяг MVP (Етап 1 — базовий MVP)

Статус: **запропоновано — очікує затвердження власником** · Дата: 2026-11-20
Пов'язані: [product-feature-map.md](product-feature-map.md) · [existing-wireframes-inventory.md](existing-wireframes-inventory.md) · [product-roadmap.md](product-roadmap.md) · [decisions.md](decisions.md)

## Визначення MVP
Нова людина за одну сесію і без акаунта може: відповісти на запитання онбордингу, отримати безпечну персональну норму калорій (або план без норми), швидко записувати їжу в прийоми, виправляти помилки і бачити прогрес за сьогодні відносно норми. Реліз дає змогу виміряти активацію і раннє утримання логування.

**Не в MVP:** вкладка аналітики, облік ваги, нагадування, фото / AI, пейвол. Це Етапи 2–3, бо вони або потребують даних, яких у перший день немає, або монетизують ще не підтверджену цінність.

## 2. Використання вайрфреймів у MVP

### 2.1 Використати без змін
- **Онбординг:** ON-01, ON-02, ON-03, ON-04, ON-05, ON-06, ON-07, ON-08, ON-10, ON-11 та їхні стани; гілка безпеки.
- **Базовий потік:** CT-03 (порція), CT-04 (редагування), CT-08 (швидке додавання), меню прийому, шторка позицій сесії, повідомлення зі скасуванням; кадри CT-02 «Нещодавнє» / «Збережене» / введення / результати / перше використання / офлайн (крім іконки, див. нижче); CT-07 і його стани (якщо штрихкод входить).
- **Стани CT-01:** порожній день, інший день без записів, частковий, у межах плану, понад план, завантаження.

### 2.2 Використати з дрібними правками (на затвердження власнику; тут не змінено)
| Екран | Правка | Причина |
|---|---|---|
| CT-01 | Показати без панелі вкладок і без рядка тижневого середнього; додати вхід у налаштування (наприклад, іконка в заголовку) | Прогрес — Е2 (SD-03); потрібні налаштування (SD-07) |
| CT-01 | Застосувати Q36: «+» видно на минулих днях | Затверджене рішення ще не намальоване (I-1) |
| CT-02 | Приховати іконку камери в полі пошуку; іконку штрихкоду показувати, лише якщо F-19 входить | Фото / AI перенесено на Е3 (SD-01) |
| CT-02 «Немає результатів» | Залишити «Швидко додати калорії»; приховати «Додати через фото / AI» | Те саме |
| CT-02 минулий день | Намалювати дату біля «Прийом ▾» | Q36 (I-2) |
| CT-03 | Приховати «Більше харчової цінності», якщо вміст не описано | I-7 |
| ON-09 | Переписати тексти карток «Точність» / «Кілька порад»: без обіцянки, що норма оновлюється з вагою, доки не з'явиться облік ваги | Довіра (SD-06, I-4) |

### 2.3 Наявні вайрфрейми, які варто відкласти (зберігаються як референс)
- CT-05 Камера, CT-06 Перевірка AI + усі стани AI → **Етап 3**.
- CT-01 з панеллю вкладок; рядок тижня на CT-01; стани текстів на основі тижня; банер повернення (якщо не взято як Could) → **Етап 2**.
- PR-01, PR-03, PR-04 і потік дописування з Прогресу → **Етап 2**.
- Ряди перевірки «малого» дня (сторінка 06) → **пізній Етап 2 або Етап 5**.
- PR-02 місяць → **Етап 3**.

### 2.4 Відсутні екрани чи потоки, потрібні для MVP
| # | Що відсутнє | Примітки |
|---|---|---|
| 1 | Варіант CT-01 **без норми** | Є значення за замовчуванням у специфікації (Q1 онбордингу): лише спожито, без кільця / коридору |
| 2 | **Головний екран налаштувань** + «Мій план» (перевикористати ON-10 → перерахунок ON-09) + конфіденційність і видалення даних + підтримка / про застосунок | Нова специфікація + вайрфрейми |
| 3 | **Згода / повідомлення про конфіденційність** при першому запуску | Розташування визначити з юристом; не подовжувати онбординг більше, ніж потрібно |
| 4 | **Підтвердження видалення даних** | Частина налаштувань |
| 5 | Повідомлення про джерело / ліцензію бази продуктів (якщо цього вимагає обраний постачальник) | Залежить від OQ-03 |
| 6 | Екран запуску / завантаження і загальний екран помилки | Невеликі; можуть бути системними |

### 2.5 Функції, які поки не варто розробляти
Фото / AI, голосове логування, місячна аналітика, перевірка «малого» дня, адаптивний двигун норми, цілі Б/В/Ж, інтеграція з Health, система акаунтів (до рішення OQ-05), будь-яка гейміфікація, соціальні функції, облік тренувань / води / голодування.

## 3. Швидкі шляхи, які MVP має зберегти
| Шлях | Ціль |
|---|---|
| Повторний продукт, типова порція | Сьогодні → + на прийомі → + на рядку «Нещодавнє» → Готово = **3 натискання**, без введення тексту (D7) |
| Новий продукт, своя порція | + → ввести → натиснути рядок → змінити → Додати → Готово |
| Від першого запуску до першого запису | Вітання → 7 кроків запитань → Ваш план → Записати першу їжу (D10) |
