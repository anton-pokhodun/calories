# Перелік наявних екранів і потоків

Статус: **на перегляд власнику продукту** · Дата: 2026-11-20 · оновлено 2026-11-20 після доопрацювання вайрфреймів ([wireframe-audit.md](wireframe-audit.md) §9–§10)
Пов'язані: [current-product-assessment.md](current-product-assessment.md) · [product-feature-map.md](product-feature-map.md) · [mvp-scope.md](mvp-scope.md)

Джерелом правди щодо поведінки екранів лишаються наявні специфікації; цей файл — покажчик зі статусом і пропонованим етапом. Файл Figma: `fBMPokQnQHUsG1G0KfOuJn` (сторінки 00 Overview, 01 Onboarding, 02 Daily Logging, 03 Progress, 04 Components, 05 Archive). Обсяг MVP за рішеннями власника 2026-11-20: фото / AI, штрихкод і Прогрес лишаються в MVP (SD-01…SD-03 відхилено), налаштування — у MVP (SD-07).

## Позначення статусів
| Статус | Значення |
|---|---|
| **Реалізовано** | Працює в застосунку. **Жоден пункт не має цього статусу — коду застосунку в репозиторії немає.** |
| **Спроєктовано** | Описано в специфікації і намальовано в low-fi вайрфреймах із прототипними переходами |
| **Частково спроєктовано** | Описано, але бракує станів у кадрах або кадри відстають від затвердженого рішення |
| **Не спроєктовано** | Потрібне (або згадане), але немає ні специфікації, ні кадрів |
| **Потребує уточнення** | Поведінка залежить від відкритого питання |

Шляхи: **J1** Перший запуск (онбординг → перший запис) · **J2** Щоденне логування · **J3** Виправлення запису · **J4** Перегляд прогресу · **J5** Оплата / керування планом · **J6** Керування профілем і даними.
Етапи: див. [product-roadmap.md](product-roadmap.md). «Е1» = Етап 1 (базовий MVP) тощо.
