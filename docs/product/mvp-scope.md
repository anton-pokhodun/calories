## Визначення MVP
Нова людина за одну сесію і без акаунта може: відповісти на запитання онбордингу, отримати безпечну персональну норму калорій (або план без норми), швидко записувати їжу в прийоми, виправляти помилки і бачити прогрес за сьогодні відносно норми. Реліз дає змогу виміряти активацію і раннє утримання логування.

**Не в MVP:** облік ваги, нагадування, місячна аналітика, перевірка «малого» дня (SD-04, SD-05 — відкриті), пейвол. Це Етапи 2–3, бо вони або потребують даних, яких у перший день немає, або монетизують ще не підтверджену цінність.

## 3. Швидкі шляхи, які MVP має зберегти
| Шлях | Ціль |
|---|---|
| Повторний продукт, типова порція | Сьогодні → + на прийомі → + на рядку «Нещодавнє» → Готово = **3 натискання**, без введення тексту (D7) |
| Новий продукт, своя порція | + → ввести → натиснути рядок → змінити → Додати → Готово |
| Від першого запуску до першого запису | Вітання → 7 кроків запитань → Ваш план → Записати першу їжу (D10) |
