# Карта функцій продукту

Статус: **на перегляд власнику продукту** · Дата: 2026-11-20
Пов'язані: [mvp-scope.md](mvp-scope.md) · [product-roadmap.md](product-roadmap.md) · [monetization-strategy.md](monetization-strategy.md)

Усі функції, знайдені у вайрфреймах і документації, плюс потрібні, але відсутні. **Стан реалізації для кожної функції — «Не реалізовано»** (коду застосунку немає), тому колонка нижче показує стан *дизайну*.

Позначення — Дизайн: **D** спроєктовано · **P** частково · **N** не спроєктовано · **C** лише концепція. Складність (відносна, лише для планування): **S** мала · **M** середня · **L** велика · **XL** дуже велика / зовнішня залежність. Бізнес-цінність: **H/M/L** (висока / середня / низька).
