## 1. Модель

**Freemium з регулярною підпискою (щомісячна і річна), що з'являється на Етапі 3** — після того, як Етапи 1–2 покажуть, що люди активуються і продовжують записувати.

| | Безкоштовно | Premium [Г] |
|---|---|---|
| Мета | Дати повну цінність базового обліку калорій | Заощадити час, автоматизувати, дати глибше розуміння |
| Онбординг і персональна норма | ✓ | ✓ |
| Пошук, Нещодавнє, Збережене, швидке «+», порції, швидке додавання калорій | ✓ | ✓ |
| Сканування штрихкоду | ✓ (за замовчуванням) — див. §4 H-M3 | ✓ |
| Редагування / видалення, минулі дні | ✓ | ✓ |
| «Сьогодні» з коридором | ✓ | ✓ |
| Прогрес · тиждень, деталі дня | ✓ | ✓ |
| Облік ваги і базовий тренд | ✓ | ✓ |
| Нагадування | ✓ | ✓ |
| **Логування фото / AI** | Обмежена безкоштовна спроба (наприклад, кілька розпізнавань) [Г] | Без обмежень (розумне використання) |
| **Місяць і довша історія, тренди** | — | ✓ |
| **Адаптивна норма** (Етап 5) | — | ✓ [Г] |
| Надалі: цілі Б/В/Ж, розширена синхронізація з Health | — | Кандидати |

Принцип: **безкоштовний користувач може добре вести облік калорій завжди.** Premium прибирає зусилля і додає розуміння.

## 2. Оцінка наявних вайрфреймів щодо моделі

| Наявний екран | Роль у монетизації | Примітка |
|---|---|---|
| Іконка камери в полі пошуку CT-02 | **Головна точка входу в Premium** — людина сама виявляє намір скористатися AI | Натискання безкоштовним користувачем (після безкоштовних спроб) відкриває пейвол; більше ніде на CT-02 пейволу немає |
| CT-02 «Немає результатів» → «Додати через фото / AI» | Другорядна точка входу | «Швидко додати калорії» поруч має лишатися безкоштовним, щоб людина ніколи не застрягала |
| CT-05 / CT-06 | Екрани Premium-функції | Перевикористовуються без змін |
| Перемикач «Тиждень / Місяць» на PR-01 | Точка входу в Premium для місяця | Тиждень лишається безкоштовним |
| PR-02 Місяць | Екран Premium-функції | Перевикористовується |
| ON-09 «Ваш план» | Можливе місце для *м'якої* пропозиції в експериментах Етапу 4 | Суперечить D10 «одразу до першого запису»; не на Етапі 3 (SD-10) |
| Налаштування (відсутні) | Статус підписки, відновлення покупок, керування | Вимога правил магазинів |
| CT-01, CT-03, CT-04, CT-08 | **Ніколи** не показують пейвол | Суттєві робочі процеси |

**Чи потрібен пейвол?** Так — один екран пейволу (порівняння планів + пробний період / покупка), що відкривається в контексті дії. Ще не спроєктовано.

## 3. Де пропозиції можуть з'являтися природно
1. Натискання на іконку камери / «Додати через фото / AI» після вичерпання безкоштовних спроб.
2. Натискання «Місяць» у Прогресі.
3. (Етап 5) Коли адаптивний двигун має достатньо даних: «Ваша норма тепер може підлаштовуватися під ваші реальні результати» — пропозиція в момент, коли цінність можна показати.
4. Налаштування → рядок «Premium» (пасивно).
5. (Лише експеримент Етапу 4) Пропозиція, яку можна закрити, після першого записаного дня, а не до першого запису.

Ніколи: до завершення онбордингу, під час запису, на «Сьогодні», як повторюване нагадування, через push-сповіщення.

## 4. Припущення, що потребують перевірки

| ID | Припущення | Як перевірити | Коли |
|---|---|---|---|
| H-M1 | Фото / AI цінують настільки, щоб за нього платити | Використання безкоштовної спроби → перегляд пейволу → конверсія; якісні інтерв'ю | Е3 |
| H-M2 | Вартість одного AI-розпізнавання лишає додатну маржу за обраної ціни | Ціни постачальника × розпізнавань на Premium-користувача | Е3 до запуску |
| H-M3 | Безкоштовний штрихкод більше допомагає утриманню, ніж заробив би платний | Порівняти використання й утримання; за потреби пізніший тест | Е3–Е4 |
| H-M4 | Місяць / довга історія — розуміння, за яке готові платити | Частка натискань «Місяць» серед безкоштовних; конверсія з цієї точки | Е3 |
| H-M5 | Адаптивна норма — найсильніша довгострокова причина платити | Утримання й конверсія користувачів двигуна проти контролю | Е5 |
| H-M6 | Річний план із пробним періодом кращий за лише щомісячний | Співвідношення планів, конверсія з пробного | Е3–Е4 |
| H-M7 | Контекстні пейволи конвертують, не погіршуючи утримання D30 безкоштовних | Утримання безкоштовних проти бази Етапу 2 | Е3 |
| H-M8 | Рівень ціни для цільового ринку | Цінові тести / огляд ринку (даних зараз немає) | Е3 (OQ-09) |

## 5. Запобіжники
- Утримання D30 безкоштовних користувачів не має падати після запуску пейволу (критерій виходу з Етапу 3).
- Без маніпулятивних патернів: зрозуміла ціна, дата завершення пробного періоду, просте скасування.
- Пропозиції оновлення з'являються у відповідь на дію людини, не більше однієї пасивної пропозиції за сесію.
- Користувачі режиму безпеки (без норми) ніколи не бачать пропозицій, орієнтованих на схуднення.
